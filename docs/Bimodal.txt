Kimi: 您的思路方向是对的——**先尝试理论最优的 $k_{\max}=AN^{2/3}$，若导致 $k_{\min}<2$ 则退而求其次**，这符合书中"在约束下最大化 $\langle k^2\rangle$"的精神。

但您给出的公式有**关键笔误和逻辑缺口**，需要修正：

---

### 一、核心笔误：总度守恒

双峰网络中 $N-1$ 个节点度为 $k_{\min}$，1 个节点度为 $k_{\max}$，总度必须等于 $2|E|$：

$$(N-1)\cdot k_{\min} + k_{\max} = 2|E|$$

您多处写成了 $|E|$（如 `k_max=|E|-2*(N-1)`），这会导致总度只有一半，配置模型无法正确生成。应统一改为 $2|E|$。

---

### 二、修正后的完整判断逻辑

```python
// 输入：N = |V|, M = |E|
// 步骤1：由固定成本计算平均度和理论常数 A
k_avg ← 2*M / N
A     ← ( (2 * k_avg^2 * (k_avg - 1)^2) / (2*k_avg - 1) )^(1/3)   // 书中公式7.67

// 步骤2：尝试理论最优 k_max = A * N^(2/3)
k_max_theory ← A * N^(2/3)
k_min_theory ← (2*M - k_max_theory) / (N-1)

// 步骤3：判断理论最优是否可行
IF k_min_theory >= 2 AND k_max_theory <= N-1 THEN
    // 情况A：理论最优可行，严格按书中公式
    k_min ← ROUND(k_min_theory)        // 或 CEIL，保证整数
    k_max ← 2*M - (N-1)*k_min          // 由总度守恒反推，确保精确
    
ELSE IF (2*M - 2*(N-1)) <= N-1 THEN

    k_min ← 2
    k_max ← 2*M - 2*(N-1)              // 修正：总度是 2M，不是 M
    
ELSE
    // 情况C：边数过多，即使 k_min=2 也会导致 k_max > N-1（简单图上限）
    k_max ← N - 1
    k_min ← CEIL( (2*M - (N-1)) / (N-1) )
END IF

// 步骤4：奇偶性修正（配置模型要求总度为偶数）
total_deg ← (N-1)*k_min + k_max
IF total_deg % 2 != 0 THEN
    k_max ← k_max + 1                  // 微调枢纽度，对成本影响可忽略
END IF
```

Function Compute_Bimodal_Params(N, M):
    k_avg ← 2.0 * M / N
    
    // 鲁棒性前提：书中要求 k_min > 1，实验取最小整数 2
    IF k_avg < 2.0 THEN
        RETURN FALSE, NULL                    // 平均度不足，无法构造
    END IF
    
    // 尝试书中理论最优 k_max = A*N^(2/3)
    A ← ((2 * k_avg^2 * (k_avg - 1)^2) / (2*k_avg - 1))^(1/3)
    k_max_theory ← A * N^(2/3)
    k_min_theory ← (2*M - k_max_theory) / (N-1)
    
    feasible ← FALSE
    IF k_min_theory >= 2.0 AND k_max_theory <= N-1 THEN
        k_min ← CEIL(k_min_theory)
        k_max ← 2*M - (N-1)*k_min
        feasible ← TRUE
        PRINT "采用书中理论最优: k_max≈", k_max, "k_min=", k_min
    ELSE IF (2*M - 2*(N-1)) <= N-1 THEN
        // 边数偏少，优先保证 k_min=2
        k_min ← 2
        k_max ← 2*M - 2*(N-1)
        feasible ← TRUE
        PRINT "理论最优不可行，采用固定成本最优: k_max=", k_max, "k_min=2"
    ELSE
        // 边数过多，受简单图上限约束
        k_max ← N - 1
        k_min ← CEIL((2*M - (N-1)) / (N-1))
        feasible ← TRUE
        PRINT "受简单图约束: k_max=N-1, k_min=", k_min
    END IF
    
    // 奇偶修正
    IF ((N-1)*k_min + k_max) % 2 != 0 THEN
        k_max ← k_max + 1
    END IF
    
    RETURN feasible, (k_min, k_max)
END

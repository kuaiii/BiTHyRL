# 相图：给定 `(N, ⟨k⟩)` 时该用哪种双峰构造

> 本文档把书（Barabási, *Network Science*, §7.16 与进阶阅读 7.G）的**渐近**最优解
> 变成一张以 `(N, ⟨k⟩)` 为坐标的**可判定相图**，并给出每个区域里两个峰的比例。
>
> 全部结论只依赖度序列与 GCC，不使用 CSA 或 `H_C`，因此与服务域语义
> （复制式/划分式）无关——见 `docs/protocol/cascade_and_metrics.md` §9。
>
> 复现：`python scripts/test_phase_theory.py`（六项自检）、
> `python scripts/phase_diagram.py`（网格实验）。实现：`src/topology/phase_theory.py`。

## 0. 为什么书中的公式不能直接用

书中的最优度分布是**两点分布**：`r` 比例的节点度 `k_max`，其余度 `k_min`，
固定 `⟨k⟩`，令 `r → 0` 解驻点，得

```
k_max = A(⟨k⟩)·N^(2/3),   A = [ 2⟨k⟩²(⟨k⟩−1)² / (2⟨k⟩−1) ]^(1/3)          (书 7.69)
```

它回答了"形状"，但没回答三个工程问题：

1. **尺度**：`r → 0` 是极限。任何真实网络都有 `r ≥ 1/N`，`N` 有限时偏多少？
2. **可行性**：`k_max` 长到 `A N^(2/3)` 需要从低度层抽走 `2A N^(2/3)` 的度。
   低度层还剩多少？还能连通吗？
3. **替代**：若上面任一条不满足，"类双峰"该往哪个方向退？

下面用三个无量纲量把这三问一次解决。

## 1. 核心恒等式

设 `n_h` 个 hub（度 `k_max`），`n_l = N − n_h` 个低度节点（度 `k_low`），记

```
ρ = n_h / N         hub 层节点占比（书中的 r）
κ = k_max / k_low   峰比（集中度）
x = n_h·k_max / M   hub 边占全图边的比例
μ = 2·e_ll / n_l    残余层**内部**平均度
```

度守恒给出 `M = n_h·k_max + e_ll`，代入 `⟨k⟩ = 2M/N` 立刻得到

$$
\boxed{\;\langle k\rangle \;=\; \mu\,(1-\rho) \;+\; 2\rho\,k_{\max}\;}
\tag{1}
$$

**(1) 是本文件的全部起点。** 它把"两个峰各占多少"压成一维：给定 `⟨k⟩`，
`(ρ, k_max, μ)` 只有两个自由度，而 `μ` 由另两个定死。

三个等价形式，分别对应三种读法：

$$
\rho=\frac{\langle k\rangle-\mu}{2k_{\max}-\mu}
\tag{2}
$$

$$
x \;=\; 1-\frac{\mu(1-\rho)}{\langle k\rangle}
\qquad\Longleftrightarrow\qquad
\mu=\frac{\langle k\rangle(1-x)}{1-\rho}
\tag{3}
$$

$$
k_{\rm low}=\frac{\langle k\rangle-\rho k_{\max}}{1-\rho},
\qquad
\mu = k_{\rm low}-\frac{\rho k_{\max}}{1-\rho}
\tag{4}
$$

(3) 说明 **`x` 与 `μ` 是一对**：hub 拿走越多边，残余层必然越薄——没有免费的边。
(4) 说明 **书中的 `k_min` 与真正的 `μ` 差一项 `ρk_max/(1−ρ)`**，这一项是后面所有
"理论失效"的根源。

> **验证**（`scripts/test_phase_theory.py` T1）：在构造图 `N=150/200/500`、
> `n_h=1..5` 上，用实测 `μ` 与实测 `k_max` 代入 (1)，与 `2M/N` 的相对误差 < 1e−9。

## 2. 可行域：三道约束，两道有闭式判据

| 编号 | 约束 | 含义 | 等价形式 |
|---|---|---|---|
| C1 | `μ ≥ 2` | 残余层无叶子（否则摘 hub 后被逐个点掉） | `k_max ≤ (M−N+n_h)/n_h` |
| C2 | `μ ≥ 3` | 残余层自身还能扛随机失效（`f' = 1−1/(μ−1) ≥ 1/2`） | 见命题 2 |
| C3 | `κ > 1` | 严格双峰（否则退化为单峰/近正则） | `k_max > ⟨k⟩` |

**C1 与残差约束完全等价**（T2 逐点验证，`max|μ(cap)−2| < 1e−12`）。
它不是"额外的工程限制"，而是 (1) 的直接推论：

$$
\mu\ge 2
\iff \langle k\rangle-2\rho k_{\max}\ge 2(1-\rho)
\iff n_h k_{\max}\le M-N+n_h
\iff k_{\max}\le\frac{M-N+n_h}{n_h}
$$

### 命题 1（`⟨k⟩ ≤ 3` 时无解，与 `N` 无关）

*证明.* C2 要求 `μ ≥ 3`，由 (1)：

```
⟨k⟩ = μ(1−ρ) + 2ρk_max ≥ 3(1−ρ) + 2ρk_max
```

而 C3 要求 `k_max > k_low ≥ μ ≥ 3`，故 `2ρk_max > 6ρ`，于是

```
⟨k⟩ > 3(1−ρ) + 6ρ = 3 + 3ρ > 3
```

反之 `⟨k⟩ ≤ 3` 时上式不可能成立。∎

**这条推论的杀伤力在于它与 `N`、与构造算法、与训练都无关。** 五张真实 SDN 拓扑里
四张 `⟨k⟩ < 3`（`GtsCe 2.59`、`Cogentco 2.47`、`UsCarrier 2.39`、`Colt 2.31`），
它们在结构上就不存在"残余层能自持"的双峰解。

### 命题 2（精确的 `N_min`）

令 `ρ = 1/N`（单 hub）并取书中的 `k_max = A N^(2/3)`，C2 化为

$$
2A\,N^{2/3} \;\le\; N(\langle k\rangle-3)+3
\tag{5}
$$

右端减左端记作 `g(N)`。`g(0)=3>0`，`g` 先减后增（`g' = (⟨k⟩−3) − (4/3)A N^{-1/3}`），
故 (5) 成立当且仅当 `N ≥ N_min`，`N_min` 是 `g` 的唯一正根。

常见写法 `N_min ≈ [2A/(⟨k⟩−3)]^3` 是忽略 `+3` 的结果，在 `⟨k⟩ → 3⁺` 时偏差达数量级
（`Chinanet`，`⟨k⟩=3.14`：近似式给 `4.7×10⁴`，精确式给同一量级但 `+3` 项使小 `N`
一侧多出一段可行区，见 `min_size()` 的实现注释）。

### 命题 3（书中 7.65 的误差项就是 `A·N^(−1/3)`）

书 7.65 用 `k_min`（低度节点**总**度）写定向攻击阈值：

```
f^target = r + (1−r)(1 − 1/(k_min − 1))                        (书 7.65)
```

但摘掉 hub 之后，低度节点只剩层内边，其度是 `μ` 而**不是** `k_min`。由 (4)：

$$
k_{\rm low}-\mu=\frac{\rho k_{\max}}{1-\rho}
\;\;\xrightarrow[\rho=1/N,\;k_{\max}=AN^{2/3}]{}\;\;
\frac{A\,N^{-1/3}}{1-1/N}
\tag{6}
$$

即 **7.65 的误差是 `A·N^(−1/3)` 阶，不是 `o(1)` 的高阶小量**。代入实际尺度：

| `N` | `N^(−1/3)` | `A·N^(−1/3)`（`⟨k⟩=2.6`，`A=2.47`） | 与 `⟨k⟩−2 = 0.6` 之比 |
|---|---|---|---|
| 150 | 0.188 | 0.465 | **78%** |
| 500 | 0.126 | 0.311 | 52% |
| 2000 | 0.079 | 0.196 | 33% |
| 10⁴ | 0.046 | 0.114 | 19% |

`N=150` 时误差吃掉了 78% 的余量，`μ` 被顶到 2.00——**残余层恰好是一个环**，
`f' = 1−1/(μ−1) = 0`，摘掉 hub 的瞬间残余层失去自持能力。这不是"略有偏差"，
而是定性错误。

## 3. 相图：两个临界尺度，四个档

**这里有一个容易混淆、必须分开的点**：`μ ≥ 3` 能否实现，与"书中解 `k_max = A N^(2/3)`
能否实现"，是**两个不同的门槛**，差一档。

| 临界 | 定义 | 闭式（忽略 `+1` 项） | 物理含义 |
|---|---|---|---|
| `N_cap` | `A N^(2/3) = M−N+1` | `[A/(⟨k⟩/2−1)]³` | 低于此值，`k_max` 被 C1 夹住，`μ = 2` |
| `N_min` | `2A N^(2/3) = N(⟨k⟩−3)+3` | `[2A/(⟨k⟩−3)]³` | 高于此值，书中解同时满足 `μ ≥ 3` |

因为 `(⟨k⟩−3)/2 = ⟨k⟩/2 − 1.5 < ⟨k⟩/2 − 1`，恒有 `N_cap < N_min`。

**注意 `⟨k⟩ > 3` 时 `μ = 3` 本身几乎总是可行**：取 `ρ = 1/N`、
`k_max = [N(⟨k⟩−3)+3]/2`，则

```
cap − k_max = N(⟨k⟩/2−1)+1 − [N(⟨k⟩−3)+3]/2 = (N−1)/2 > 0
```

对任意 `N ≥ 2` 成立。所以"B 区不是不可行，而是**取理论 `k_max` 会导致 `μ < 3`**"。
这个区分对论文表述很重要：不能说"B 区不能做双峰"，只能说"B 区的双峰必须把
`k_max` 压到理论值以下"。

| 档 | 判据 | `μ` | 单 hub 的 `k_max` | 残余层形态 |
|---|---|---|---|---|
| **A** | `⟨k⟩ ≤ 3` | `2`（`N<N_cap`）→ `⟨k⟩`（`N≫N_cap`） | `M−N+1`（被夹） | 环 + 少量弦 |
| **B1** | `⟨k⟩ > 3`，`N < N_cap` | `2` | `M−N+1`（被夹） | 环 |
| **B2** | `⟨k⟩ > 3`，`N_cap ≤ N < N_min` | `(2, 3)` | `A N^(2/3)`（未夹） | 环 + 较多弦 |
| **C** | `N ≥ N_min` | `⟨k⟩ − 2A N^(−1/3) ≥ 3` | `A N^(2/3)` | 二维、自持 |

`⟨k⟩ ≤ 3` 时 `N_min = ∞`（命题 1），所以 A 档不可能升到 C 档——**这是它的定义性特征**。
A 档随 `N` 增大只能把 `μ` 从 2 抬到 `⟨k⟩ < 3`，永远差一口气。

典型值（`scripts/phase_theory.py` 的 `min_size` 与 `N_cap`）：

| `⟨k⟩` | `A` | `N_cap` | `N_min`（`μ=3`） |
|---|---|---|---|
| 2.2 | 1.60 | 4.1×10³ | ∞ |
| 2.6 | 2.02 | 3.1×10² | ∞ |
| 3.0 | 2.43 | 1.1×10² | ∞ |
| 3.5 | 2.94 | 61 | 1.6×10³ |
| 4.5 | 3.96 | 32 | 141 |
| 7.0 | 6.47 | 17 | 32 |

## 4. 各区的最优比例

**(2) 是比例的唯一来源**，下面三个区的差别只是把它代入不同的边界条件。

### C 区（`N ≥ N_min`）：书中解可行

```
ρ* = 1/N,        k_max* = A·N^(2/3)        ← 这是 f^tot 口径的角点解
κ* = A N^(2/3) / (⟨k⟩ − A N^(−1/3)),        μ* = ⟨k⟩ − 2A N^(−1/3) ≥ 3
```

`ρ* = 1/N` 即"hub 越少越好"，这正是书里 `r → 0` 的结论；`k_max*` 的标度
`k_max*·ρ^(2/3) → A` 在 T4 中被数值验证（`N` 从 2000 到 2×10⁵，比值 2.81 → 5.08
对 `A=5.47`，收敛慢但方向正确）。

**但这是 `f^tot` 的角点，不是 `R̄` 的。** 按 §5 的机制，`R̄` 在**任何**区都偏好
`k_max` 落在平台内（`⌈⟨k⟩⌉+1` 附近），而不是顶到 `A N^(2/3)`。C 区的意义是
"书中的解终于可行了"（`μ ≥ 3`），而不是"它是 `R̄` 的最优解"。论文若要报告 `R̄`，
必须同时给出两行：书中角点与 `R̄` 平台。

### B 区（`⟨k⟩ > 3`，`N < N_min`）：压缩单 hub

```
ρ* = 1/N,        k_max* = M − N + 1 = N(⟨k⟩/2 − 1) + 1
κ* = (M−N+1) / (⟨k⟩ − 1),                  μ* = 2
```

**注意 `μ* = 2` 是恒等式而非近似**：把 `k_max = M−N+1`、`ρ=1/N` 代入 (1) 得
`μ = (⟨k⟩ − 2(M−N+1)/N)/(1−1/N) = 2`。所以 B 区的单 hub 与 A 区一样，残余层是环。
**B 区与 A 区的唯一区别是 hub 的绝对大小**，而这一区别来自 `⟨k⟩ > 3` 是否成立。

### A 区（`⟨k⟩ ≤ 3`）：`k_max` 取下界，`n_h` 取最少

C1 在 A 区恒为紧约束或接近紧约束。若只在 `μ=2` 边界上移动，由 (2) 得一条一维曲线

$$
\rho(k_{\max})=\frac{\langle k\rangle-2}{2(k_{\max}-1)}
\tag{7}
$$

它的右端（`k_max` 最小）是 `ρ = (⟨k⟩−2)/6`，对应族右边界 `n_h = (M−N)/3`。
一维族扫描（`scripts/phase_diagram.py`）确实在这里取到 `argmax`（`⟨k⟩=2.6`、
`N=120/240/480` 的实测 `n_h* = 12/20/48`，`ρ* ≈ 0.10`，与式 (7) 逐位吻合）。

**但这不是最优。** 式 (7) 假定 `μ=2`，而 `μ` 越大越好（残余层越厚）。
把 `k_max` 从 `cap` 降到 `⌈⟨k⟩⌉+1` 但不增加 `n_h`，可以在同一个 `k_max` 下把 `μ` 抬高。
`⟨k⟩=2.6`、`N=240`、`n_h=1`（5 seed × 10 次洗牌的稳健值）：

| | `k_max=4` | `k_max=73`（=`cap`） |
|---|---|---|
| `μ` | 2.58 | 2.00 |
| `R̄` | **0.270** | 0.189 |

**同一个图规模、同样的边数与连通性，`R̄` 差 43%。**

所以 A 区的正确答案是

$$
n_h^*=1,\qquad k_{\max}^*=\lceil\langle k\rangle\rceil+1,\qquad
\mu^*=\frac{\langle k\rangle-2/N}{1-1/N}\approx\langle k\rangle
\tag{8}
$$

即 **`μ` 取到接近 `⟨k⟩`（而不是 2），同时 `κ` 取到下界**。两者在 `n_h=1` 处同时达成，
因为 `n_h` 越小，留给低度层的度越多。

> **为什么要在此处明确否定式 (7) 的解**：族扫描只能沿 `k_max = min(A N^(2/3), M−N+n_h)`
> 这条线走，而 `n_h` 减小时 `cap = (M−N+n_h)/n_h` 急剧变大，于是 `k_max` 被推高、
> `μ` 被压到 2。轨迹本身把两个变量绑反了。联合扫描（§5）才能解耦。

## 5. 两个峰的比例：只有一个自由度有实质影响

### 5.1 联合扫描的结论：`R̄` 是平台，`L̄` 是斜坡

沿构造器自己的一维轨迹（`k_max = min(A N^(2/3), M−N+n_h)`）扫描 `n_h`，会得到
"最优点在族右端"的结论。**这是轨迹的伪影**：该轨迹把 `k_max` 绑死在 `n_h` 上，
`n_h ↓` 使 `cap = (M−N+n_h)/n_h` 急剧变大，于是 `k_max` 被推高、`μ` 被压到 2。
两个变量被绑反了。

放开 `k_max`、固定 `n_h=1`，多 seed 稳健测量（`N=240`、`⟨k⟩=2.6`、
5 个构造种子 × 每次 10 次随机洗牌）：

| `k_max` | 4 | 6 | 8 | 12 | 16 | 24 | 32 | 48 | 73 (=cap) |
|---|---|---|---|---|---|---|---|---|---|
| `R̄` | 0.270 | **0.273** | 0.273 | 0.268 | 0.263 | 0.265 | 0.251 | 0.240 | 0.189 |
| `R̄` 标准差 | 0.006 | 0.002 | 0.006 | 0.003 | 0.005 | 0.008 | 0.008 | 0.009 | 0.009 |
| `L̄` | 7.49 | 7.43 | 7.39 | 7.23 | 7.05 | 6.52 | 6.13 | 5.44 | **4.56** |
| `κ` | 1.54 | 2.32 | 3.10 | 4.69 | 6.29 | 9.56 | 12.9 | 19.9 | 31.7 |
| `μ` | 2.58 | 2.56 | 2.54 | 2.51 | 2.48 | 2.41 | 2.34 | 2.21 | 2.00 |

三条读数：

1. **`R̄` 在 `k_max ∈ [4, 24]` 上是一个平台**，极差 0.263–0.273，小于 1.5 个标准差。
   单点 `argmax`（第 6 或第 8）是噪声，`k_max=4` 与 `k_max=24` 没有可分辨的差别。
2. **`k_max > 24` 之后 `R̄` 单调降**，到 `cap` 时掉 30%。
3. **`L̄` 全程单调降**，`k_max` 从 4 到 `cap` 降 39%。

所以"最优点"不是一个点，而是**一段平台**；在平台内选哪一点，由时延预算决定。

### 5.2 机制：hub 拿走多少度，就等于残余层少多少弦

这个平台有精确来源。由 `e_ll = M − n_h k_max` 与 `n_low = N − n_h`：

$$
\text{弦数} \;=\; e_{ll}-n_{\rm low} \;=\; M-N+1-k_{\max} \;=\; \texttt{cap}-k_{\max}
\tag{9}
$$

`μ = 2` 时残余层是一个**纯环**（弦数 0）；每多一条弦，环就多一处"绕行"，
定向切割要多切一处才能把它断开。所以 `k_max` 不是在"调整 hub 大小"，
而是在**直接消耗残余层的冗余**：

```text
k_max = 4   → 69 条弦（N=240, ⟨k⟩=2.6）  → R̄ = 0.270
k_max = 24  → 49 条弦                     → R̄ = 0.265
k_max = 73  →  0 条弦（纯环）             → R̄ = 0.189
```

平台的存在对应"弦足够多时，环的脆弱性被稀释"：从 69 条弦减到 49 条，
`R̄` 只掉 2%；从 49 条减到 0 条，掉 28%。**冗余的边际价值递减。**

### 5.3 `n_h` 是二阶量

同一 `k_max=4`、`N=240`、`⟨k⟩=2.6` 下，`n_h` 从 1 增到 16，`R̄` 从 0.270 到 0.264
（−2%）。原因是 `n_h` 增大只改变"多少条边被 hub 拿走"的分布方式，而
(9) 决定的弦总数 `M−N+1−n_h k_max` 在 `k_max` 不变时变化很小。

因此

$$
\frac{\partial \bar R}{\partial k_{\max}} \;\gg\; \frac{\partial \bar R}{\partial n_h}
\qquad\Longrightarrow\qquad
\text{主比例是 } \kappa=k_{\max}/k_{\rm low},\quad \rho \text{ 是二阶修正}
\tag{10}
$$

### 5.4 为什么会反过来：`f^tot` 与 `R` 在 `k_max` 上反向

（续）

| `⟨k⟩=2.6`, `n_h=1` | `k_max=4` | `k_max=73`（=cap） |
|---|---|---|
| `f^rand`（解析） | 0.745 | 0.900 |
| `f^target`（解析） | 0.000 | 0.000 |
| `f^tot` | 0.745 | **0.900** ← 偏好大 `k_max` |
| `R_random`（实测） | **0.339** | 0.227 |
| `R_targeted`（实测） | **0.221** | 0.062 |
| `R̄`（实测） | **0.280** | 0.144 ← 偏好小 `k_max` |
| `L̄`（实测） | 7.66 | **4.36** ← 偏好大 `k_max` |

两条机制：

1. **阈值 vs 面积。** `f^tot` 是崩溃**点**，`R` 是崩溃**前的整段面积**。方差大
   （`k_max` 大）把崩溃点推后，但一旦崩溃，GCC 从 1 直接掉到接近 0；方差小则
   崩溃更早但更平缓，面积反而大。
2. **Molloy–Reed 的适用前提不成立。** `f^rand = 1 − 1/(⟨k²⟩/⟨k⟩ − 1)` 假定局部
   树状（无短环）。`μ ≈ 2` 的残余层全是环，短环无处不在，该式给出的阈值
   （`k_max=4` 时 0.745）与实际下降曲线完全不符——实测 `R_random = 0.339`，
   而环上随机摘点的面积上界就是 0.5。**`f^tot` 在 `μ≈2` 的图上不是"偏一点"，
   而是用错了模型。**

第 2 条同时解释了 §3 表里 A/B1 档的存在意义：`μ=2` 不只是"残余层薄"，
而是"残余层的统计物理模型从树状切换到了环状"，两套理论不通用。

### 5.5 于是"最优比例"必须带目标函数

| 目标 | `k_max*` | `n_h*` | 出处 |
|---|---|---|---|
| `f^tot`（书） | `A N^(2/3)`（顶到上界） | `1` | 书 7.67–7.69；T4 验证标度 |
| `R̄` 单目标 | `[⌈⟨k⟩⌉+1, ~0.1N]` 的**平台**，平台内不可分辨 | `1` | §5.1 稳健表 |
| `R̄` + 时延预算 `L_max` | 平台内满足 `L̄ ≤ L_max` 的最大值 | `1` | §5.6 前沿 |
| 加分散（大 `⟨k⟩`） | 同上 | `n_h ≈ N(⟨k⟩−3)/(2k_max−3)` | §5.3 |

**这就是 `BiT-HyRL` 的位置**：解析式给的是 `f^tot` 口径的角点解（`k_max` 顶到上界），
而工程目标是 `R̄`（或在时延约束下的 `R̄`），两者在 `k_max` 上方向相反。RL 的价值
不在于"找到解析解已经给出的点"，而在于**在两条曲线的拐点之间按时延预算选点**，
并吸收离散化、整数度、局部聚合结构等解析式覆盖不到的效应。

### 5.6 `k_max` 扫出的 (R̄, L̄) 前沿

同一张稳健表（§5.1）就是前沿本身：`k_max` 从 4 增到 `cap`，`L̄` 降 39%
（7.49 → 4.56），`R̄` 在平台内只掉 2%，出平台后掉 30%。

| `k_max` | 4 | 8 | 16 | 24 | 32 | 48 | 73 |
|---|---|---|---|---|---|---|---|
| `R̄` | 0.270 | 0.273 | 0.263 | 0.265 | 0.251 | 0.240 | 0.189 |
| `L̄` | 7.49 | 7.39 | 7.05 | 6.52 | 6.13 | 5.44 | 4.56 |

**双峰不是"更鲁棒"，而是"用鲁棒换时延"**，交换比率由 `k_max` 唯一决定，而平台
意味着**换取前半段时延几乎不付鲁棒代价**：`k_max` 从 4 到 24 换到 13% 的时延改进，
`R̄` 只损失 2%。这正是 SDN 场景想要的——控制面时延是硬指标，鲁棒性有余量即可。

这与 `docs/eval/topology_benchmark.md` §3 的结论一致（该校：近正则 `R̄` 第一但
`L̄` 差 20–34%），也是"为什么不用解析解"的最终答案：解析解在 `k_max=cap` 一端，
恰好是 `R̄` 最差的地方。

## 6. 决策表（可直接写进论文）

```
输入：N, M（或真实图 G）
1. ⟨k⟩ ← 2M/N
2. 断言连通且 ⟨k⟩ > 2，否则先加边（双峰在该预算下不存在）

3. 若 ⟨k⟩ ≤ 3：
       zone = A
       n_h = 1,  k_max = ⌈⟨k⟩⌉+1        ← 双峰下界，μ≈⟨k⟩
       预期 κ ≈ (⌈⟨k⟩⌉+1)/⟨k⟩ → 1，R̄ 取该区上界

4. 否则：
       A ← A(⟨k⟩)
       N_min ← root of  N(⟨k⟩−3)+3 − 2A N^(2/3)
       若 N < N_min： zone = B
              n_h = 1,  k_max = M−N+1    ← 受压单 hub，μ = 2
       否则：        zone = C
              —— f^tot 口径：n_h = 1, k_max = round(A N^(2/3))
              —— R̄  口径：n_h = 1, k_max = ⌈⟨k⟩⌉+1（同 A 区）
              两者都报，标注口径

5. 报告 (ρ, κ, x, μ) 与 zone；若 μ < 2 则判不可构造

6. 若另有平均时延预算 L_max：
       在上面两条 R̄ 曲线之间扫 k_max，取满足 L̄ ≤ L_max 的最小 k_max
       （§5.4 的前沿表就是这条曲线）
```

**`BiT-HyRL` 在表中的位置**：A 区与 B 区的解析解都落在约束边界上（`k_max` 取上界、
`μ=2`），而实测最优往往在边界内侧一点点（`f^tot` 有内点，`R̄` 对 `k_max` 不单调）。
这一段边界附近的连续松弛正是 RL 搜索的空间——**解析解给区域，RL 给边界内的偏置**。
这也解释了为什么 RL 搜出来的 `k_max` 是 5~15：它落在 B 区（`k_max=cap` 附近）
而不是 C 区（`AN^(2/3)`，在 SDN 尺度上大到不可行）。

## 7. 实验验证（35 个 `(N, ⟨k⟩)` 点）

`scripts/phase_diagram.py`：6 个 `⟨k⟩` × 6 个 `N`（60…1920），每点扫族内 `n_h`，
共 35 个有效点、`n_random=3`、固定种子。**注意本节只用这张表验证"分区判据"，
不用它确定最优比例**——一维族扫描在比例上是不可靠的（见 §7.3）。

### 7.1 分区切换点与 `N_min` 预测一致

| `⟨k⟩` | `N_min`（式 5） | 实测 `regime` 切换 | 结论 |
|---|---|---|---|
| 2.2 / 2.6 / 3.0 | ∞（命题 1） | 全部 `I_unreachable`，`μ* = 2.00–2.61` | ✓ |
| 3.5 | 1615 | `N=960` 为 II，`N=1920` 转 III | ✓ |
| 4.5 | 141 | `N=120` 为 II，`N=240` 转 III | ✓ |
| 7.0 | 32 | `N=60` 起全部 III | ✓ |

四个 `⟨k⟩` 的切换点全部落在 `N_min` 的相邻网格档内，**没有一处偏移超过一档**。

### 7.2 `μ` 的闭式在 III 区精确

`μ* = ⟨k⟩ − 2A N^(−1/3)`（式 4 与 `ρ=1/N`）：

| `⟨k⟩` | `N` | 公式 | 实测 `μ*` | 差 |
|---|---|---|---|---|
| 3.5 | 1920 | 3.028 | 3.028 | 0.000 |
| 4.5 | 240 | 3.238 | 3.238 | 0.000 |
| 4.5 | 480 | 3.495 | 3.495 | 0.000 |
| 4.5 | 1920 | 3.866 | 3.866 | 0.000 |
| 7.0 | 480 | 5.357 | 5.357 | 0.000 |
| 7.0 | 1920 | 5.961 | 5.961 | 0.000 |

六个点逐位一致。这也说明 (1) 与 (4) 不是近似式，而是**在 `ρ = 1/N` 时的恒等式**。

### 7.3 一维族扫描在"比例"上不可靠（必须联合扫描）

同一个 `(N, ⟨k⟩) = (480, 2.6)`：

| 方法 | 最优点 | `R̄` |
|---|---|---|
| 一维族扫描（`k_max` 跟随 `n_h`） | `n_h=48, k_max=4` | 0.234 |
| 一维族扫描（`n_h=1`，`k_max=cap=145`） | `n_h=1` | 0.174 |
| **联合扫描（`n_h=1`, `k_max` 自由）** | `n_h=1, k_max≈4–12` | **0.261**（5 seed × 10 次洗牌） |

一维扫描给出的 0.234 比联合扫描低 **10%**；在 `(240, 2.6)` 上差距更大
（0.261 vs 0.271，4%）。原因见 §5.1：族轨迹把 `k_max` 与 `n_h` 绑反。

**这本身是一条要给审稿人的方法论说明**：任何"沿构造族扫描"的最优性声明，
都必须先证明该族的参数化没有把两个独立变量绑在一起。

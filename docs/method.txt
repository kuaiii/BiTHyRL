User: 那就是将整个模型统一为一个PPO强化学习模型，模型第一步，是基于双峰网络对网络拓扑进行微调；第二部是进行控制器选择。
Kimi: 将拓扑重构与控制器选择统一为**单一 PPO 策略网络**是可行的，核心思路是构建一个 **Phase-Aware 统一动作序列**：策略网络在同一个观测空间下，通过阶段掩码（Phase Masking）依次输出"拓扑微调动作"和"节点选择动作"。

以下是完整的架构重构方案，包含接口定义与给师弟的任务分解。

## 一、统一 PPO 架构概览

```
原始图 G (gml)
    │
    ▼
[共享编码器] ──► 节点表示 h_v ∈ R^d, 图表示 g ∈ R^d
    │
    ├──► [Phase 1: 拓扑微调头] ──► 边操作序列 (B 步)
    │         │
    │         ▼
    │    G' (微调后的双峰网络)
    │
    └──► [Phase 2: 控制器选择头] ──► 节点序列 (K 步)
              │
              ▼
         最终评估 ──► 统一奖励 R
```

**关键设计**：一个 `TopologyPolicy` 网络，两个解码头，共享 GNN 编码器。通过 **Phase Embedding** 告知网络当前处于哪个阶段。

## 二、状态空间（Observation Space）

状态需要包含"当前图结构"和"阶段信息"，且必须支持动态图（每步增删边）。

```python
class UnifiedObservation:
    """
    统一观测空间，支持动态图
    """
    # 节点级特征 (N, F_node)
    x: torch.Tensor          # 基础特征: Node2Vec(256) + DRE(256) + 节点状态(3)
                             # 节点状态: [is_hub, is_controller, is_modified]
    
    # 图结构 (支持动态边)
    edge_index: torch.Tensor       # 当前有效边 (2, E_current)
    edge_mask: torch.Tensor      # (E_max,) 原始边掩码 + 新增边
    added_edges: torch.Tensor    # (E_add, 2) 本轮新增的边
    
    # 阶段与预算信息
    phase: int                   # 1=拓扑微调, 2=控制器选择
    step_in_phase: int           # 当前阶段已走步数
    budget_remaining: int        # 剩余预算 (B_rem 或 K_rem)
    
    # 全局统计
    global_feat: torch.Tensor    # (F_global,) 图直径、平均度、代数连通性等
```

**动态图处理优化**：不频繁重建 `nx.Graph`，而是维护 `edge_mask` 和 `added_edges`，在 PyG 中通过 `edge_index[:, edge_mask]` 获取当前有效边。

## 三、动作空间（Action Space）—— 核心设计

### 3.1 Phase 1: 拓扑微调（Topology Refinement）

动作定义为 **(候选边, 操作类型)**。为避免 $O(N^2)$ 动作空间，使用 **动态候选边池（Dynamic Candidate Pool）**：

```python
class TopologyAction:
    """
    拓扑微调动作
    """
    candidate_edge_idx: int      # 在候选边池中的索引 (0 ~ M-1, M=100)
    operation: int               # 0=添加该边, 1=删除该边
```

**候选边池生成（每阶段开始时计算）**：
```python
def generate_candidate_pool(G_state, node_embed, M=100):
    """
    基于节点表示生成 Top-M 候选边
    """
    # 1. 计算所有潜在边的分数（节点表示内积 + 结构偏置）
    #    潜在边 = 原始图中不存在的边（可添加） + 原始图中存在的边（可删除）
    #    但全计算是 O(N^2)，需剪枝
    
    # 2. 剪枝策略：
    #    - 对 hub 节点：只考虑与其他 hub 的连边（优化核心）
    #    - 对 leaf 节点：只考虑与 top-5 最近 hub 的连边（优化接入）
    #    - 已存在的 leaf-leaf 边作为"可删除"候选
    
    # 3. 分数计算：score(u,v) = MLP(concat(h_u, h_v, |h_u-h_v|, g))
    #    取 Top-M 作为候选池
    
    return candidate_pool  # (M, 2) 边列表 + scores
```

**双峰结构保持约束**（通过动作掩码实现）：
- 禁止删除导致 hub 不连通的边（除非有替代路径）
- 禁止 leaf 拥有超过 `max_leaf_degree` 条边（防止 leaf 变成 hub）
- 禁止 hub 数量低于 `min_hub_count`

### 3.2 Phase 2: 控制器选择（Controller Selection）

与当前设计一致，但观测基于**微调后的图**：

```python
class SelectionAction:
    node_idx: int                # 在剩余节点中的索引
```

**动作掩码**：
- 已选控制器节点
- 已失效节点（在 Phase 1 中被删除的节点，若允许删节点）

### 3.3 阶段切换机制

```python
# 统一轨迹收集
def collect_unified_trajectory(G, B_budget, K_budget):
    G_state = G.copy()
    phase = 1
    selected_controllers = []
    
    # ---------- Phase 1: 拓扑微调 ----------
    for step in range(B_budget):
        obs = make_observation(G_state, phase=1, budget=B_budget-step)
        action = policy.get_action(obs, phase=1)  # 输出 (edge_idx, op)
        
        # 执行动作
        u, v = candidate_pool[action.edge_idx]
        if action.operation == 0:
            G_state.add_edge(u, v)
        else:
            G_state.remove_edge(u, v)
        
        # 阶段 1 奖励：0（稀疏）或基于渗流阈值的微小塑形奖励
        reward = 0.0
        store_transition(obs, action, reward)
    
    # ---------- Phase 2: 控制器选择 ----------
    for step in range(K_budget):
        obs = make_observation(G_state, phase=2, selected=selected_controllers)
        action = policy.get_action(obs, phase=2)
        
        node = node_list[action.node_idx]
        selected_controllers.append(node)
        
        # 最后一步计算统一奖励
        if step == K_budget - 1:
            reward = calculate_unified_reward(G_state, selected_controllers, G_original)
        else:
            reward = 0.01
        
        store_transition(obs, action, reward)
```

## 四、策略网络架构（TopologyPolicy）

```python
class TopologyPolicy(nn.Module):
    """
    统一拓扑微调 + 控制器选择策略网络
    """
    def __init__(self, in_channels=512, hidden_dim=128, heads=4, num_layers=3, 
                 M_candidates=100, dropout=0.1):
        super().__init__()
        
        # ===== 共享 GNN 编码器（轻量级） =====
        # 从 6 层 12 头降为 3 层 4 头，减少过平滑
        self.input_proj = nn.Linear(in_channels, hidden_dim)
        self.gnn_layers = nn.ModuleList([
            GATConv(hidden_dim, hidden_dim // heads, heads=heads, concat=True, dropout=dropout)
            for _ in range(num_layers)
        ])
        self.gnn_norms = nn.ModuleList([LayerNorm(hidden_dim) for _ in range(num_layers)])
        self.phase_embed = nn.Embedding(2, hidden_dim)  # Phase 1/2 嵌入
        
        # ===== Phase 1: 拓扑微调头 =====
        # 边分数生成：基于节点对
        self.edge_scorer = nn.Sequential(
            nn.Linear(hidden_dim * 3, hidden_dim),  # [h_u, h_v, h_u*h_v]
            nn.ReLU(),
            nn.Linear(hidden_dim, 1)  # 边重要性分数
        )
        self.topo_op_head = nn.Linear(hidden_dim, 2)  # [添加概率, 删除概率]
        
        # ===== Phase 2: 控制器选择头 =====
        self.controller_head = nn.Sequential(
            nn.Linear(hidden_dim * 2, hidden_dim),  # [h_v, g_global]
            nn.ReLU(),
            nn.Linear(hidden_dim, 1)  # 节点价值分数
        )
        
        # ===== Critic 头（共享） =====
        self.critic = nn.Sequential(
            nn.Linear(hidden_dim * 2, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 1)
        )
    
    def forward(self, x, edge_index, phase, candidate_pool=None, 
                selected_mask=None, global_feat=None):
        """
        Args:
            x: (N, F) 节点特征
            edge_index: (2, E) 当前边
            phase: int (1 or 2)
            candidate_pool: (M, 2) Phase 1 候选边池
            selected_mask: (N,) Phase 2 已选掩码
            global_feat: (F_g,) 全局特征
        """
        # --- 共享编码 ---
        h = self.input_proj(x)
        h = F.elu(h)
        
        for gat, norm in zip(self.gnn_layers, self.gnn_norms):
            h_new = gat(h, edge_index)
            h_new = norm(h_new)
            h_new = F.elu(h_new)
            h = h + h_new  # 残差
        
        # 阶段嵌入
        phase_emb = self.phase_embed(torch.tensor(phase, device=h.device))
        h = h + phase_emb.unsqueeze(0)  # 广播到所有节点
        
        # 全局图表示
        g_global = global_mean_pool(h, batch=None)  # (hidden_dim,)
        if global_feat is not None:
            g_global = torch.cat([g_global, global_feat], dim=-1)
        
        # ===== Phase 1: 拓扑微调 =====
        if phase == 1:
            assert candidate_pool is not None
            M = candidate_pool.size(0)
            
            # 提取候选边端点表示
            h_u = h[candidate_pool[:, 0]]  # (M, hidden_dim)
            h_v = h[candidate_pool[:, 1]]    # (M, hidden_dim)
            h_uv = h_u * h_v                 # 交互特征
            
            edge_feat = torch.cat([h_u, h_v, h_uv], dim=-1)  # (M, 3*hidden_dim)
            edge_scores = self.edge_scorer(edge_feat).squeeze(-1)  # (M,)
            
            # 操作类型分数（全局决策）
            op_logits = self.topo_op_head(g_global)  # (2,)
            
            # 联合概率：P(edge, op) = P(edge) * P(op|edge) 的简化版
            # 实际输出 M 条边的分数，操作类型由独立头决定
            # 更简洁：输出 2M 个动作（M 条边 × 2 种操作）
            combined_logits = edge_scores.unsqueeze(1) + op_logits.unsqueeze(0)  # (M, 2)
            combined_logits = combined_logits.view(-1)  # (2M,)
            
            # 动作掩码：过滤非法操作（如删除不存在的边，添加已存在的边）
            action_mask = self._get_topo_mask(candidate_pool, edge_index)
            combined_logits = combined_logits.masked_fill(~action_mask, -1e9)
            
            probs = F.softmax(combined_logits, dim=-1)
            value = self.critic(g_global)
            return probs, value, candidate_pool
        
        # ===== Phase 2: 控制器选择 =====
        else:
            # 节点分数
            h_global = torch.cat([h, g_global.unsqueeze(0).expand(h.size(0), -1)], dim=-1)
            node_scores = self.controller_head(h_global).squeeze(-1)  # (N,)
            
            # 掩码已选节点
            if selected_mask is not None:
                node_scores = node_scores.masked_fill(selected_mask, -1e9)
            
            probs = F.softmax(node_scores, dim=-1)
            value = self.critic(g_global)
            return probs, value
```

## 五、统一奖励函数设计

```python
def calculate_unified_reward(G_final, controllers, G_original, 
                             attack_ratio=0.15, w_gcc=0.6, w_disp=0.2, 
                             w_cost=0.2, alpha=0.01):
    """
    统一奖励：韧性 + 分散度 - 重构成本
    """
    # 1. GCC 保持率（对抗多攻击）
    gcc_scores = []
    for method in available_attack_methods:
        seq = dismantle(G_final, method)
        retention = simulate_attack(G_final, controllers, seq, attack_ratio)
        gcc_scores.append(retention)
    gcc_reward = min(gcc_scores)  # 最坏情况
    
    # 2. 分散度
    disp_reward = calculate_dispersion(G_final, controllers)
    
    # 3. 重构成本惩罚
    #    - 边修改数量
    #    - 与原始图的边差异
    #    - hub 比例偏离目标
    E_orig = set(map(tuple, map(sorted, G_original.edges())))
    E_final = set(map(tuple, map(sorted, G_final.edges())))
    edge_diff = len(E_orig.symmetric_difference(E_final))
    
    # 归一化：最大容忍差异为 |E_orig| 的 30%
    max_diff = max(1, int(0.3 * G_original.number_of_edges()))
    cost_penalty = alpha * (edge_diff / max_diff)
    
    # 4. 双峰结构惩罚（可选）
    #    如果最终图不是双峰结构，给予惩罚
    hub_nodes = [n for n, d in G_final.degree() if d > threshold]
    hub_ratio = len(hub_nodes) / G_final.number_of_nodes()
    bimodal_penalty = abs(hub_ratio - 0.15)  # 偏离目标 0.15
    
    reward = (w_gcc * gcc_reward + 
              w_disp * disp_reward - 
              w_cost * (cost_penalty + 0.1 * bimodal_penalty))
    
    return reward
```

### 6.1 课程学习（必须开启）

```python
def get_curriculum_config(epoch, total_epochs):
    """
    逐步增加难度：小图 → 大图，少预算 → 多预算，简单攻击 → 全攻击
    """
    progress = epoch / total_epochs
    
    if progress < 0.2:
        return {
            'node_range': (20, 100),
            'B_budget': 2,      # 拓扑微调预算
            'K_budget_ratio': 0.05,
            'attack_methods': ['degree'],
            'aggregation': 'mean'
        }
    elif progress < 0.5:
        return {
            'node_range': (50, 300),
            'B_budget': 5,
            'K_budget_ratio': 0.08,
            'attack_methods': ['degree', 'betweenness'],
            'aggregation': 'mean'
        }
    else:
        return {
            'node_range': (100, 500),
            'B_budget': 10,
            'K_budget_ratio': 0.1,
            'attack_methods': 'all',
            'aggregation': 'min'
        }
```

### 6.2 训练加速策略

| 问题 | 解决方案 |
|------|----------|
| 每步重建图结构慢 | 使用 `edge_mask` 张量，避免重建 `nx.Graph` |
| Node2Vec 每图重复计算 | 阶段 1 开始时计算一次，阶段 2 复用；拓扑微调阶段只用 GNN 传播 |
| 大图前向传播慢 | Batch 处理同规模图；使用 PyG 的 `NeighborLoader` 或子图采样 |
| 候选边池计算慢 | 每 5 步更新一次候选池，而非每步 |

### 6.3 两阶段训练预热（稳定性技巧）

完全端到端训练初期极不稳定，建议：

1. **预训练 Phase 2**：先固定原始图（不微调拓扑），只训练控制器选择头，直到 reward 收敛到 0.55+。
2. **联合训练**：解冻 Phase 1 头，降低 Phase 1 学习率（如 Phase 2 的 0.3 倍），联合优化。
3. **交替冻结**：每 10 epoch 交替冻结一个头，防止梯度冲突。

## 八、风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| **动作空间仍然过大** | 500 节点图候选边池 M=100 时，Phase 1 动作空间 200，但有效动作可能仅 20 个 | 使用动作掩码 + 非法动作惩罚；若仍困难，将 M 降至 50 |
| **拓扑微调导致图不连通** | 奖励崩溃 | 在 `GraphState` 中强制维护连通性：删除边后检查连通，若不连通则拒绝该动作（mask 掉） |
| **两阶段梯度冲突** | Phase 1 损失与 Phase 2 损失量级不同 | 使用梯度裁剪 + 损失平衡系数；或先预训练 Phase 2 |
| **训练时间爆炸** | 每图 B+K 步，每步一次 GNN forward | 使用轻量级 GNN（3 层）；缓存 Node2Vec；大图子图采样 |
| **双峰结构难以保持** | 动作后 hub/leaf 界限模糊 | 不强制严格双峰，而是在奖励中加入"度分布熵"惩罚，鼓励双峰形态 |

## 九、总结

当前框架的核心问题是**"重构与选择解耦"**。统一 PPO 的关键在于：

1. **Phase-Aware 动作序列**：将拓扑微调（B 步）和控制器选择（K 步）串联为同一条轨迹，用阶段嵌入区分。
2. **动态候选边池**：将 $O(N^2)$ 的边操作空间压缩为 $O(M)$（M=50~100），通过 GNN 节点表示生成候选。
3. **统一奖励**：韧性 + 分散度 - 重构成本，让策略自动学习"是否值得修改这条边"。
4. **课程预热**：先学选择，再联合微调，避免初期梯度混乱。

**建议立即执行**：让师弟先实现 **T1（GraphState）+ T2（CandidatePool）+ T3（TopologyPolicy 骨架）**，用一个 50 节点小图验证两阶段动作序列能跑通（reward 能正常回传），再逐步扩展到大图和完整训练。
